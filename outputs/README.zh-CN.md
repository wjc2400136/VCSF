# 复现输出

[English](README.md) | [简体中文](README.zh-CN.md) | [项目首页](../README.zh-CN.md)

在固定 ODA 环境、仓库根目录执行。本源码包没有作者结果载荷。
按[主指南](../docs/current-public-reproduction.zh-CN.md)及对应主题指南检查
真实输出命名空间与成功条件。

直接实验入口默认执行；`--plan-only` 不调用模型，但部分入口仍写入不可变计划叶目录。
先查看入口帮助。`--max-images` 结果仅为诊断，不作正式 mAP 或规范检查点发布。

保留各入口实际产生的计划、任务分配、状态、原始日志、未舍入记录、
汇总、源码/输入/检查点绑定及自动 CSV/TeX/绘图输出。保留十二项标准指标。
缺失、失败和未运行不是零，分别用 NR、ERR 或经审计的结构性跳过。

成功要求完整预期覆盖、失败记录为零及独立保存结果核验，不能只凭退出码。
源码守卫通过或 CPU 计划不等于 CUDA 执行或科学接受。
包守卫不遍历运行载荷，源码身份只覆盖随包源码命名空间及三个目录指南。

失败后保留完整叶目录与部分证据。掉线后先确认 PID/启动身份。
修复实际原因，只在新叶目录补明确选择的缺失子集。
不自动恢复、不覆盖、不合并运行。载荷删除需要另行明确范围、
验证目标并确定备份/恢复方案；本指南不授权删除。
