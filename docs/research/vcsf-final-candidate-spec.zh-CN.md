# VCSF-Attack 冻结开发候选规范

状态：开发候选已冻结，实现等价性已验证，独立 COCO 正式验证尚未进行。

## 威胁模型与计算预算

对于像素空间输入 `x`，VCSF-Attack 生成满足下式的 `x_adv`：

```text
||x_adv - x||_infinity <= 4/255
```

在执行器使用的 0--255 张量中，这等价于最多四个像素值。固定比较日程严格使用二十次完整的源检测器反向图像等价量：

1. 一次检测器语义初始化更新；
2. 十九次特征存活更新；
3. 零次辅助检测器前向；
4. 零次辅助检测器反向；
5. 不查询目标模型，不使用额外代理模型、生成器、扩散模型或视觉语言模型。

冻结目标不使用真实框或标签。公共攻击接口仍接收这些字段，但由于空间支持已经选择为全局干净特征能量，实现会明确忽略它们。

## 阶段一：检测器语义初始化

令 `p_j(x)` 表示源检测器的可微置信度。执行器优先使用可微 post-NMS 表面；该表面不存在或已脱离梯度图时，使用公开的可微 pre-NMS 回退。经过与数据类型一致的安全截断后，定义：

```text
z_j(x) = log p_j(x) - log(1 - p_j(x))
L_init(x) = log sum_j exp(z_j(x)).
```

第一次计入预算的反向传播最小化 `L_init`，从而在干净点处为后续的干净/对抗方向特征目标提供一个非静止的检测器语义位移。此次更新的优化器状态随后被丢弃。丢弃状态只是更简单的阶段边界，不是命名模块，也不计作贡献点。

## 阶段二：视图一致的跨阶段特征存活抑制

剩余十九次更新中的每一次，都从固定区间 `[2/3,4/3]` 采样同一个尺度与位置变量 `xi_t`。同一变换 `T_xi_t` 同时作用于干净图像和当前对抗图像，避免目标函数比较两个不同的随机视图。

检测器只对拼接后的干净/对抗图像对执行一次前向。冻结特征表面包含六层：

- neck 的第 0、1、2 层；
- backbone 最后的三张特征图。

对于第 `l` 层和位置 `u`，定义干净能量与通道方向：

```text
e_l(u) = mean_c F_l(T_xi_t(x))[c,u]^2
fhat_l(u) = F_l(T_xi_t(x))[:,u] / ||F_l(T_xi_t(x))[:,u]||_2
ahat_l(u) = F_l(T_xi_t(x_adv))[:,u] / ||F_l(T_xi_t(x_adv))[:,u]||_2.
```

该层存活的方向证据为：

```text
c_l = sum_u e_l(u) <fhat_l(u), ahat_l(u)>
      / max(sum_u e_l(u), 1e-6).
```

六层不使用学习权重或混合系数，而以平滑瓶颈聚合：

```text
L_feature = log((1/6) sum_l exp(c_l)).
```

最小化该目标会抑制 backbone/neck 联合表面中仍然最强的干净方向证据。“存活”仅指这里明确定义和测量的干净对齐方向证据，不表示对检测器内部语义作因果解释。

## 更新规则

对于每次图像梯度 `g_t`，先移除逐通道空间均值，再用整张图像的平均绝对幅值归一化：

```text
gbar_t = (g_t - mean_HW(g_t)) / max(mean_CHW(|g_t - mean_HW(g_t)|), 1e-12).
```

初始化阶段只使用一次 `sign(gbar_0)` 并丢弃状态。特征阶段重新建立普通一阶 momentum：

```text
m_t = gbar_t                              第一次特征更新
m_t = 0.7 m_(t-1) + gbar_t                后续特征更新
delta_t = Project_[−4,+4](delta_(t-1) - sign(m_t)).
```

投影同时保证 0--255 的有效图像范围。Momentum 是标准优化器选择，不构成创新主张。

## 开发证据与贡献层级

下列数值均来自完整 1000 图开发协议。在排除六个 source-matched 白盒单元后，从未舍入 raw mAP 计算配对差值，数值越低越好。

| 问题 | 配对差值 | 覆盖 | 解释 |
|---|---:|---:|---|
| cross-stage 表面下的尺度作用 | `-0.12374351581002638` | 90/90 单元、6/6 源、16/16 目标 | 占主导的保留因素 |
| 尺度条件下的 cross-stage 表面作用 | `-0.022803203951081555` | 86/90、6/6、16/16 | 主目标的材料性证据 |
| 一次初始化作用 | `-0.015002332557435922` | 90/90、6/6、16/16 | 有材料性的辅助原则 |
| reset 相对 carryover | `-0.002151926360121533` | 74/90、6/6、16/16 | 广泛但非材料性，不计作贡献 |
| scale 与 surface 的 interaction | `+0.009471140039330521` | 仅 23/90、0/6、4/16 为负 | 拮抗，不得声称协同 |

因此，论文层级应当是：

1. 一个主要的检测器特定目标：视图一致的跨阶段全局特征存活抑制；
2. 一个辅助初始化原则：特征优化前的一次、计入预算的平滑检测器 log-odds 更新；
3. 一个实证贡献：在相同二十次反向预算下进行六源、十六目标的广泛评估。

三个保留因素的收益不需要相等，但必须如实报告不平衡的贡献度；每个被命名的方法选择都必须通过预注册的开发材料性门槛。

## 新颖性与引用边界

现有文献已经包含变换增强迁移、同步特征输入视图、多层特征攻击、检测器多阶段目标、余弦/方向特征损失、输出到特征的阶段优化、momentum、随机对称性破除以及阶段 reset。上述原子设计均不得单独声称为新颖。

本次定向审查支持的有限区别是这里冻结的检测器特定整合：一次计入预算的平滑检测器 log-odds 位移，随后执行十九次同步尺度更新，并在全局干净能量加权的六层 backbone/neck 方向存活瓶颈上优化。
