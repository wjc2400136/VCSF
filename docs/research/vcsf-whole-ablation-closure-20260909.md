## Questions and appropriate controls

| Question | Design and boundary |
| --- | --- |
| Core scale, cross-stage and initializer contributions | A scale-by-surface-by-initializer two-level factorial, with other settings fixed to one bound configuration. An initializer deletion changes the risk/feature schedule; report that schedule instead of pretending only the initial pixel state changed. |
| Scale processing and range | The registered scale operator-by-half-width study. It is one module, not evidence of complete ablation coverage. |

| Spatial weight and feature aggregation | Energy/uniform weighting by maintained/simple-mean aggregation factorial. Spatial support is a separate contrast unless a further interaction is justified. |
| Gradient centering and momentum | A targeted centering-on/off by momentum-zero/final-default factorial. Other momentum values remain a one-dimensional sensitivity study. |
| Final robustness and cost | Only the author-frozen final configuration receives the separately registered five-seed study. Report the complete sixteen-target panel, source-excluded BB Mean, target-specific changes, actual paired time/memory and reference/gradient accounting. |

These controls define questions, not a mandate to retain an obsolete component.
If an isolated replacement removes a component, update the final attribution
design prospectively and preserve the earlier exploration rather than forcing
unrelated controls into the final table. New implementation/configuration
identities cannot inherit outcomes from a different baseline.

### Selection and finite closure

Select within the declared stage using the complete target panel, paired changes,
actual cost and implementation complexity. Never select from rounded values,
drop difficult targets, combine individual winners automatically, or call a
retrospective bootstrap interval selection-adjusted confirmation. Record an
explicit keep/change/reject decision and rationale after each stage. A working
baseline change invalidates only dependent attribution rows, not prior history.

Allow one final consistency pass over affected contrasts after the working
baseline stabilizes. If that pass undermines the intended contribution, narrow
the claim or reject the candidate; do not start an unlimited tuning loop. A
substantive replacement can be proposed with evidence, but it requires a newly
bounded prospective plan when it exceeds these cells. No positive AP effect,
particular ranking, or global optimum is a required outcome.

The completion checklist is: (a) every retained claim maps to a same-baseline
counterfactual; (b) claimed interactions have complete factorial contrasts;
(c) initializer-budget and stage-count confounds have the specified controls;
(d) each admitted group has 5,000 image records and all sixteen target records,
verified hashes, preserved failure evidence and accepted generated outputs;
(e) formal final promotion and final-only seed stability are closed or honestly
rejected with an owner decision; (f) reports state single-source and reused-data
limits and preserve negative results. Implementation checks alone satisfy none
of the numerical completion conditions.

1. Execute the registered scale stage first, retaining every outcome. Other
   stages require exact descriptors, contrasts and selection rules before use.
2. Update the working baseline only with documented complete-panel evidence and
   a clear decision chronology. This is not author-only final public promotion.
3. Once the configuration stabilizes, identify affected core contrasts by exact
   parameter and implementation identity. Refresh those contrasts, not the
   entire exploratory history or accepted clean/other-method baselines.
4. Final promotion remains an explicit owner decision. Only then bind and run
   final-configuration stability and affected six-source main result updates.
5. Close the ablation programme when each claimed contribution has an appropriate
   counterfactual, each claimed interaction has its factorial contrast, obvious
   count/budget confounds are addressed or disclosed, and all final attribution
   rows share the same baseline with complete evidence and generated reports.

An AP contrast is a conditional performance observation, not a proof of mechanism
or global optimality. Five seeds on reused COCO validation do not restore dataset
independence. Single-source ablations are complete within the declared source
scope; they do not imply universal mechanisms. Preserve the observed Swin
disagreements separately, without forcing new Swin ablation jobs. The final
six-source transfer scope is unchanged.
