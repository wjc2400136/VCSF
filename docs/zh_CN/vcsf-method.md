## 配置

| 设置 | 选定的 A10 设置 |
| --- | --- |
| 扰动上限 | 主比较中为 4/255 |
| 步长 | 1/255 |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 动量 | 85/100；进入特征更新前丢弃初始化动量 |
| 特征选择 | 父层级列表为 [0,1,2]，每阶段选三层，共六个 backbone/neck 项 |
| 几何变换 | clean/adversarial 共享几何；尺度范围 [2/3,4/3]；双线性插值、随机放置、零填充 |
| 特征目标 | 能量加权、log-mean-exp 聚合、有效支撑区域 |
| 梯度处理 | 初始化和特征更新均进行梯度中心化 |

表格解释当前选择，不能代替参数文件。选择状态 JSON 保留未舍入的解析后数值，
其 `hash_encoding` 字段给出参数的规范序列化方式。参数哈希不能绑定执行代码、输入、
检查点或结果。

## 解释边界

A10 来自原始 Faster R-CNN 单源、seed 42、全部 5,000 张 COCO val2017 图像、十六目标的
23 配置回顾性面板。复用该验证集不能建立独立确认。已记录准则优先依据未舍入、
排除源模型的受攻击 BB Mean AP；A10 在该完整家族中最低。Faster 源最终背景控制
保留完整 A10 背景。后续预先登记的 A10／仅骨干等权双源补充比较处理特定的 Faster 源反例，
不是 23 配置的完整双源排序。完整配置使用更多特征项，逐目标与次指标分歧及负结果仍须保留。
这不证明全局、全源、全指标或重复 seed 最优。

不主张统计显著、与 A01 统计等效、实测加速、跨源最优或物理计算量完全相等。
不同优化背景下的早期算子结果不能充当最终动量下的交互证据。
额外参考前向、部分反向、时间和显存需要分别报告实际成本。

DINO 未用于攻击生成，但参与过离线 COCO 配置选择，不是未观察过的独立选型留出。
历史 A01 消融及 seed 结果仍绑定其原背景。

内部 A10 各结果家族与公开源码候选分别具有适用范围内的验收记录；这份元数据包不代替
这些记录，也不包含其可执行复现流程或原始结果表，不授予项目级软件许可证，不声称完整
公开发行或每个入口均已新做原生 GPU 验证。当前数据集为 COCO 和 VOC；BDD100K 不是
剩余实验或发行依赖。
