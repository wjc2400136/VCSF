# VCSF 科学身份

[English](../en/vcsf-method.md) | [简体中文](vcsf-method.md)

VCSF 仅指一个冻结配置。完整的解析后参数保存在
[科学身份记录](../../vcsf-scientific-identity.json)中，参数 SHA-256 为
`158acaf594c74b4f6a9c20fe28d6c2e38ef6ab9230b85f6d0b0b8b7e93dd7e9e`。
研究标识 `A01` 和共同背景组 `26` 指向同一选定配置，不是两个公开方法。

## 配置

| 设置 | 冻结值 |
| --- | --- |
| 扰动上限 | 主比较中为 4/255 |
| 步长 | 1/255 |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 动量 | 85/100；进入特征更新前丢弃初始化动量 |
| 特征选择 | 父层级列表为 [0,1,2]，每阶段选两层，共四个 backbone/neck 项 |
| 几何变换 | clean/adversarial 共享几何；尺度范围 [2/3,4/3]；双线性插值、随机放置、零填充 |
| 特征目标 | 能量加权、log-mean-exp 聚合、有效支撑区域 |
| 梯度处理 | 全过程梯度中心化 |

表格用于解释配置，不能代替参数文件。JSON 保留原始解析后数值，不进行舍入，
也不从本表重新构造参数。`hash_encoding` 字段给出了参数和清单哈希采用的规范序列化方式。

它是面向公开分发的派生记录，不是原始验收回执；不包含运维路径和私人执行记录。
