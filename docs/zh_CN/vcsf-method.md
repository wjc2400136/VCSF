## 方法配置

| 设置 | 数值或定义 |
| --- | --- |
| 主实验扰动上限 | 4/255 |
| 步长 | 1/255 |
| 更新顺序 | 一次检测器初始化，随后十九次特征更新 |
| 动量 | 85/100；进入特征更新前重置初始化动量 |
| 特征选择 | 根据注册父层列表选择三个 backbone 尾部图和三个 neck 图 |
| 几何变换 | 干净/对抗共享几何，尺度范围 [2/3,4/3]，双线性插值、随机放置和零填充 |
| 特征目标 | 干净特征能量权重、log-mean-exp 聚合及有效支持 |
| 梯度处理 | 初始化与特征更新均使用梯度中心化 |

表格用于解释方法，不代替配置文件。执行须保留完整参数、梯度路径、参考前向
和计数单位。特征反向和参考工作不能视为免费操作，也不能自动等同于完整检测器反向。

## 实验范围

公开流程为 COCO 与 Pascal VOC 主比较，采用六个独立源、十六个规范顺序目标。
输入准备、单双卡计划、执行与恢复见[主实验指南](../current-public-reproduction.zh-CN.md)。

配置敏感性分析使用已声明的 COCO 验证集进行回顾性选择，不作为同一数据上
选定配置的独立确认。完整设置与全部结果保留在
[研究来源记录](../research/vcsf-a10-configuration-recommendation-provenance.md)。
历史记录保持原身份，不改名为变化后实现的结果。
