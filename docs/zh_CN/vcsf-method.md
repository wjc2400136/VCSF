## 配置

| 设置 | 待提升的 A23 设置 |
| --- | --- |
| 扰动上限 | 主比较中为 4/255 |
| 步长 | 1/255 |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 动量 | 85/100；进入特征更新前丢弃初始化动量 |
| 特征选择 | 父层级列表为 [0,1,2]，每阶段选两层，共四个 backbone/neck 项 |
| 几何变换 | clean/adversarial 共享几何；尺度范围 [2/3,4/3]；双线性插值、随机放置、零填充 |
| 特征目标 | 能量加权、log-mean-exp 聚合、有效支撑区域 |
| 梯度处理 | 初始化和特征更新均不进行梯度中心化 |

表格解释当前选择，不能代替参数文件。选择状态 JSON 保留未舍入的解析后数值，
其 `hash_encoding` 字段给出参数的规范序列化方式。参数哈希不能绑定执行代码、输入、
检查点或结果。

## 解释边界

A23 来自 Faster R-CNN 单源、seed 42、全部 5,000 张 COCO val2017 图像、十六目标的
23 配置回顾性面板。复用该验证集不能建立独立确认。A10 在该面板主指标上的受攻击
BB AP 更低，但使用更多特征项；次指标表现混合。这是暂定的效果与复杂度取舍，
不是最优性证明。目标和次指标分歧仍须保留。

不主张 A23 与 A01 统计等效、取消中心化带来实测加速、跨源最优或物理计算量完全相等。
不同优化背景下的早期算子结果不能充当最终动量下的交互证据。
额外参考前向、部分反向、时间和显存需要分别报告实际成本。

这里没有已接受的 A23 六源、VOC、预处理、训练状态、半径或成本结果。
这份元数据包不包含可执行复现流程、已接受的 A23 结果表、软件许可授权或全项目设备验收证明。
