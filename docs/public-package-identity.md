# Public Source Distribution Identity

[English](public-package-identity.md) | [简体中文](public-package-identity.zh-CN.md)

`public-package.json` binds every shipped source, configuration, direct entry,
helper, public guide and lightweight provenance file. The separate versioned
`vcsf-a10-public-package-freeze-v1.json` binds that exact manifest and its
source map. These two control documents are explicit, not recursive self-hashes.
Neither control document is a license or scientific acceptance.

The guard checks plain project files, relative POSIX paths, hashes, the shipped
file census, local Python imports, configured runtime/AST helper dependencies,
the nine original numerical hashes, every original configuration byte and all
six original provenance bytes. It rejects missing dependencies, changed files,
symlinks and extra unbound shipped executables. Runtime data and output records
are not source identity and are validated by their own experiment contracts.

The preserved `vcsf-a10-public-source-freeze.json` describes the complete
historical author tree. A trimmed package does not satisfy that old source map.
The new guard returns an openly distinct source-closure identity and retains the
old freeze digest. It never changes historical hashes or claims that old
implementation results certify the entire new orchestration.

Nonnumeric loaded-config validation, read-only observation and physical-device
resolution helpers are relocated with exact original AST bodies. Linux ODA
interpreter checks resolve the current environment rather than embed a private
server path. Registry, factory, attack mathematics, nine numerical files, A10
parameters, MRO and original selection evidence are unchanged.

Bounded CPU imports, CLI help and no-GPU plans establish only those interfaces.
They do not establish all CUDA branches, runtime payload acceptance, distribution
rights or scientific results. Unpublished author evidence remains outside this
bundle; historical support code is not an advertised retired protocol. Follow
the [main guide](current-public-reproduction.md) for the maintained programme.

One amendment referenced by the preserved historical final-budget/training-state refresh protocols is already absent in the original tree. The manifest identifies both exact references as historical metadata, not current runtime inputs. It is not fabricated, repaired or evidence accepted by this source distribution; these historical refresh paths are not certified for execution.

The current distribution uses `lgp_public_source_distribution_v2`. The guard also
accepts the historical candidate-only v1 schema without promoting its rights or
scientific status. The inherited freeze filename stays stable, while its schema,
source map and licence boundary are rebound in this new copy. The v2 `release`
flag concerns this software-source distribution only; `science` and `formal`
remain false. Licence scope, original upstream licence bytes and both notice
guides are bound explicitly. The original A10 scientific identity keeps its
existing status and numerical hashes.
