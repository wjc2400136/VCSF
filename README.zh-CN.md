# VCSF

**面向目标检测器的特征级对抗迁移研究**

[English](README.md) | [简体中文](README.zh-CN.md)

VCSF 研究在一个目标检测器上生成的扰动如何迁移到其他检测架构。
本项目汇集冻结的方法配置、受控实验比较及目标检测迁移攻击的复现资源。

## 项目概览

| | 范围 |
| --- | --- |
| 任务 | 目标检测的迁移型对抗攻击 |
| 源模型 | 六个白盒检测器 |
| 目标模型 | 十六个检测器，覆盖两阶段、YOLO、稠密／点式和查询／集合式架构 |
| 主实验数据集 | COCO val2017 与 Pascal VOC2007 test |
| 主比较扰动约束 | L-infinity，4/255 |
| 方法身份 | 单一冻结 VCSF 配置，不按目标模型挑选配置 |

研究包含主迁移比较、受控消融、种子稳定性、输入预处理、受害模型训练状态及扰动预算实验。
上述内容描述研究范围，不表示此仓库已经提供完整可执行发行版。

## 方法概览

VCSF 将检测器初始化与跨 backbone、neck 阶段的特征更新结合。
冻结配置使用 clean/adversarial 共享几何、能量加权、log-mean-exp 聚合、梯度中心化和动量。

| 组成 | 冻结设置 |
| --- | --- |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 特征选择 | 每阶段选两层，共四个 backbone/neck 项 |
| 尺度范围 | [2/3, 4/3] |
| 几何设置 | 双线性插值、随机放置、零填充及有效支撑区域 |
| 动量 | 0.85 |

完整身份与科学解释边界见[方法说明](docs/zh_CN/vcsf-method.md)。
保留此配置不意味着它普遍最优，也不意味着它优于每个消融控制和目标模型。
