# VCSF

**面向目标检测器的特征级对抗迁移研究**

[English](README.md) | [简体中文](README.zh-CN.md)

VCSF 研究在一个目标检测器上生成的扰动如何迁移到其他检测架构。
本次发布包含历史 A01 方法元数据和当前 A23 配置选择；A23 尚不是已接受的实现或结果身份。

## 项目概览

| | 范围 |
| --- | --- |
| 任务 | 目标检测的迁移型对抗攻击 |
| 源模型 | 六个白盒检测器 |
| 目标模型 | 十六个检测器，覆盖两阶段、YOLO、稠密／点式和查询／集合式架构 |
| 主实验数据集 | COCO val2017 与 Pascal VOC2007 test |
| 主比较扰动约束 | L-infinity，4/255 |
| 方法身份 | 仅使用 VCSF 方法名；A23 已选定但尚待实现提升，不按目标模型挑选配置 |

研究包含主迁移比较、受控消融、种子稳定性、输入预处理、受害模型训练状态及扰动预算实验。
上述内容描述研究范围，不表示此仓库已经提供完整可执行发行版。

## 方法概览

VCSF 将检测器初始化与跨 backbone、neck 阶段的特征更新结合。
当前选定的 A23 配置使用 clean/adversarial 共享几何、能量加权、log-mean-exp 聚合与动量，
初始化和特征更新均不进行梯度中心化。

| 组成 | 待提升的 A23 设置 |
| --- | --- |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 特征选择 | 每阶段选两层，共四个 backbone/neck 项 |
| 尺度范围 | [2/3, 4/3] |
| 几何设置 | 双线性插值、随机放置、零填充及有效支撑区域 |
| 动量 | 0.85 |

选择边界与科学解释见[方法说明](docs/zh_CN/vcsf-method.md)。
已选参数不等于已接受的执行代码身份或最终结果。

## 科学边界

A23 来自复用 COCO val2017 的单源、23 配置回顾性面板，并非独立确认。
A10 在该面板的主指标上有较低的受攻击 BB AP，同时使用更多特征项；次指标表现混合。
不同目标上的分歧和负结果须保留。本次材料不提供已接受的 A23 六源或 VOC 结果，
也不主张实测加速、统计等效、跨源最优或物理计算量完全相等。
