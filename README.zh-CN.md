# VCSF

**面向目标检测器的特征级对抗迁移研究**

[English](README.md) | [简体中文](README.zh-CN.md)

VCSF 研究在一个目标检测器上生成的扰动如何迁移到其他检测架构。
当前配置是 A10，依据已记录的 23 配置比较及最终背景分析选定。
此仓库目前提供科学元数据与项目说明；完整可执行包仍是另行待完成的软件发行。

## 项目概览

| | 范围 |
| --- | --- |
| 任务 | 目标检测的迁移型对抗攻击 |
| 源模型 | 六个白盒检测器 |
| 目标模型 | 十六个检测器，覆盖两阶段、YOLO、稠密／点式和查询／集合式架构 |
| 主实验数据集 | COCO val2017 与 Pascal VOC2007 test |
| 主比较扰动约束 | L-infinity，4/255 |
| 方法身份 | 仅使用 VCSF 方法名；完整 A10 配置，不按目标模型挑选配置 |

研究包含主迁移比较、受控消融、输入预处理、受害模型训练状态及扰动预算实验。
上述内容描述研究范围，不表示此仓库已经提供完整可执行发行版。

## 方法概览

VCSF 将检测器初始化与跨 backbone、neck 阶段的特征更新结合。
当前选定的 A10 配置使用 clean/adversarial 共享几何、能量加权、log-mean-exp 聚合、动量与
梯度中心化；每阶段选三层，共六个特征项。

| 组成 | 选定的 A10 设置 |
| --- | --- |
| 更新顺序 | 检测器初始化，随后进行 19 次特征更新 |
| 特征选择 | 每阶段选三层，共六个 backbone/neck 项 |
| 尺度范围 | [2/3, 4/3] |
| 几何设置 | 双线性插值、随机放置、零填充及有效支撑区域 |
| 动量 | 0.85 |

选择边界与科学解释见[方法说明](docs/zh_CN/vcsf-method.md)。
当前身份记录分别绑定选定参数和九个数值源码文件；仅参数哈希不能充当结果验收证明。

## 科学边界

A10 来自原始 Faster R-CNN 单源、23 配置回顾性面板，使用复用的 COCO val2017，
优先依据未舍入、排除源模型的受攻击 BB Mean AP。已登记的最终背景控制，以及针对
A10／仅骨干方案的双源比较，共同支持已记录的裁决；后者不是 23 配置的完整双源排序。
逐目标分歧、负结果及实际成本差异均须保留。

DINO 未用于攻击生成，但曾参与离线 COCO 配置选择；DINO 和复用的验证集均不是未观察过的
独立选型留出。这些元数据不证明全局最优、统计显著、实测加速或物理计算量完全相等。
BDD100K 不在当前维护范围内。
